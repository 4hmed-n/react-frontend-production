# Profile Picture

Replace `profile.jpg` in this directory with your profile picture (JPG or PNG format).

The image will be displayed as a circular profile picture in the hero section with:
- Auto-scaling for different screen sizes
- Whirlpool effect on hover
- Rounded circular crop
- Responsive sizing (w-52 h-52 on mobile, w-64 h-64 on desktop)

Recommended image specifications:
- Format: JPG, PNG, or WebP
- Minimum size: 512x512px
- Ideal: 1024x1024px (for sharp display on retina screens)
- Aspect ratio: 1:1 (square)
- File size: < 200KB (optimized)
